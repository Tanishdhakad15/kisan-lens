# Kisan Lens – Agriculture Assistant Prototype

A beginner-friendly Streamlit prototype for an agriculture mini-project.

## Included features
- No login or registration; opens directly.
- Farm profile and soil/water inputs.
- Rule-based crop suitability ranking using soil, pH, NPK, rainfall, temperature, water and season.
- Generic crop activity planner.
- Crop photo observation records (not AI disease diagnosis).
- Optional live weather from Open-Meteo.
- Mandi return comparison using prices entered by the user.
- Language selector for 22 scheduled Indian languages. Optional online translation uses Google Translate via `deep-translator`; if unavailable, text falls back to English.

## Requirements
- Python 3.10 or newer
- Internet connection for installation, online translation and live weather

## Run on Windows
1. Extract the ZIP file.
2. Open the extracted `Kisan_Lens_Prototype` folder in VS Code.
3. Open Terminal > New Terminal.
4. Run:

```powershell
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

5. A browser tab should open. If it does not, copy the `http://localhost:8501` address shown in the terminal into Chrome.
6. Keep the terminal open while using the app. Press `Ctrl+C` in the terminal to stop it.

You can also double-click `run_kisan_lens.bat` after Python is installed.

## Important academic honesty and safety notes
This is a working *prototype*, not a production agricultural advisory service.
- Crop recommendations use transparent example rules and a small illustrative crop dataset. They are not generated by a trained AI model and must not be treated as agronomic prescriptions.
- The photo page saves observations only; it does not diagnose crop disease.
- Weather is fetched from Open-Meteo when internet access is available.
- Mandi prices are manually entered by the user; they are not live official prices.
- Regional-language translation is automatic and may be imperfect. Verify translations before field use.
- Use soil and irrigation-water laboratory reports and local Krishi Vigyan Kendra/agriculture department guidance for real crop decisions.
